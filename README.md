# 🧬 BHRe Genomic Database and Dashboard

## Overview

This project provides a complete framework for storing, processing, and exploring genomic and epidemiological data related to BHRe isolates.

## Components

- PostgreSQL database
- Streamlit dashboard
- Clinical metadata integration
- MLST import pipeline
- AMRFinderPlus import pipeline
- MOB-recon import pipeline
- Prokka import pipeline
- QUAST import pipeline

## Running the Dashboard

```bash
streamlit run dashboard_bhre.py
```
